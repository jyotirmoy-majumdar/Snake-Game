# Snake Game in C++

A classic console Snake Game made using C++.

## Features
- Smooth snake movement
- Food system
- Snake body growth
- Self collision detection
- Pause system
- Teleport through walls
- Sound effects using Beep()

## Controls
- W → Up
- S → Down
- A → Left
- D → Right
- SPACEBAR → Pause
-  → Exit game

## Language Used
- C++
